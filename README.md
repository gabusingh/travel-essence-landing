# Travel Essence Magazine Landing Page

A high-converting landing page for Travel Essence Magazine, showcasing luxury travel offerings in Africa and the Middle East.

## Features

- Modern, responsive design using Tailwind CSS
- Newsletter signup form
- Media kit download
- Contact section
- Showcase of advertorials, reviews, and docuseries

## Deployment

This site is deployed on Vercel and can be accessed at the provided URL.

## Local Development

Simply open `index.html` in your browser to view the page locally.
